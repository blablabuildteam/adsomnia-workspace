# Adsomnia Workspace

Interactive **Production Framework** process visualizer for Adsomnia. This repository will expand into the full Adsomnia Workspace platform; the current scope is the interactive workflow map.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- [Lucide React](https://lucide.dev) icons

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use `npm run dev:https` only when testing Slack OAuth locally.
